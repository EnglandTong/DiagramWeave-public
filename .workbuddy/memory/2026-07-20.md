### 重要發現（Slice 2.4.3 調試過程中）
- `od -c` 顯示 byte 時位置是 0-based 偏移，列號可能誤判；byte 級 diff 用 Python `bytes[i]` 比較最可靠。
- bash heredoc 寫 Python 含 `chr(b) if ...` 時反斜杠轉義被吞，用 `.py` 文件 + `os.system` 或純 `for` loop 列印更安全。
- 沙箱對 `rm` 大型文件和路徑操作有時攔截（如 `__diff2.py` 在 `rm` 時被攔截），分開執行命令可避免整個 pipeline 被否決。

Excel 数据 — 导入 / 导出

    
    
      
  1. 点击「下载空白模板」，得到带示例和填写说明的 Excel 文件
    2. 
      
  2. 在「节点表」「连线表」中按列名填写（列名与右侧属性、表格编辑一致）
    3. 
      
  3. 保存 Excel 后，点击「上传并导入」生成流程图
    4. 
    

    

    

      
列名（节点表）说明必填

      
编号节点编号，连线用同一编号关联是

      
简介形状上显示的一行标题建议

      
角色负责角色（如申请人、经理）否

      
形状图形类型，见模板「填写说明」sheet否

      
X / Y填写坐标后导入会按位置原样生成，不自动排版否

      
详细说明步骤详细内容介绍否

      
耗时天该步骤需时（天，可小数）否

      
泳道泳道图分区（从 0 起）否

      
图层图层编号否

      
目标页跨页引用时填目标页名称否

    怎么用：
    ① 顶部工具栏点「表格」图标打开本面板。
    ② 节点表：每行一个步骤（编号唯一），「去向」列只读，由连线自动算出。
    ③ 连线表：每行一条箭头，填起点编号、终点编号、条件（如「是/否」）；也可在画布用连线工具拖拽。
    ④ 在画布改形状/连线 → 点 ↺ 刷新；在表格改内容 → 点 ✓ 应用（会重新布局）。
    ⑤ 删除：先点击表格行使其高亮，再点「删节点/删连线」。
